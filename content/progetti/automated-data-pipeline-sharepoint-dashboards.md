## Contesto

Le schede Google Business Profile aziendali generano un patrimonio di recensioni e dati reputazionali distribuito tra le singole schede.

## Problema

Aggregare questi dati e renderli consultabili da responsabili e direttori di locale, senza dover accedere alle singole schede.

## Ruolo

Ho progettato il flusso automatizzato e prototipato le dashboard con il supporto dell'AI (*AI-assisted coding*).

## Approccio

- Acquisizione dei dati delle schede e delle recensioni in formato JSON, affiancati da Google Sheets per le informazioni operative
- Orchestrazione tramite Power Automate per alimentare i dataset di consultazione
- Prototipazione delle dashboard in HTML, CSS e JavaScript, distribuite su SharePoint

## Soluzione

```flow
caption: Workflow
- Google Sheets
- Apps Script
- XLSX / JSON
- Power Automate
- SharePoint
- Template HTML
- Dashboard
```

Il processo consente di partire da dati gestiti attraverso un'interfaccia semplice e collaborativa, elaborarli e strutturarli nei formati necessari e alimentare automaticamente dashboard HTML destinate alla pubblicazione interna.

## Risultato

Dashboard pubblicate su SharePoint che offrono a responsabili e direttori di locale viste aggregate dei dati, senza dover accedere alle singole schede.
